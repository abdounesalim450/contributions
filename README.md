# contributions

Open-source contribution findings and investigation notes, organized by project.
Each project gets its own subfolder; findings are written one file per bug
(duplicate reports of the same bug are merged, related PRs are noted inside).

## Projects

  [oss-tqdm/Github-bug-findings/README.md](oss-tqdm/Github-bug-findings/README.md)
  for the session summary and per-bug index.
